# QA Testing Portfolio — David Cullend

Manual & automation QA testing portfolio, built while following a structured 8-week self-study plan.

## About

Aspiring QA Engineer focused on functional testing, test case design, and (from Week 3 onward) test automation with Selenium/Playwright. This repository documents real, hands-on work — not just theory — organized week by week.
